Meridian

세상을 탐문하고 최신 뉴스를 읽어 견문과 지식을 넓혀가는 개인 뉴스 매거진

카테고리

  • AI — OpenAI, Anthropic, Google 등 주요 벤더 업데이트 및 AI 뉴스
  • AX — AWS, GCP, Azure 등 클라우드·아키텍처·현업 적용 사례
  • 광고 — 디지털 광고 업계 트렌드와 주요 매체 정보
  • 마케팅 — 카테고리별 광고주 이벤트 및 마케팅 뉴스

사용법

  • npm run fetch — RSS 수집 및 Claude 요약 실행
  • npm run dev — 로컬 매거진 서버 시작
