Apple × Claude: 온디바이스 AI 통합

Apple Foundation Models 프레임워크에 Claude를 통합하는 Swift 패키지가 공개됐다. 온디바이스 모델과 동일한 API로 Claude를 호출할 수 있어, 개발자가 클라우드와 로컬 모델을 코드 변경 없이 전환할 수 있다.

로컬 AI 전환 흐름 가속

프라이버시와 비용 절감을 이유로 Claude/GPT를 로컬 모델로 완전 대체한 개발자들의 경험이 HN에서 화제를 모았다. CrankGPT는 물리적 크랭크로 AI 토큰을 생산하는 실험적 프로젝트로, 클라우드 의존 탈피에 대한 재치 있는 접근이다.

멀티모델 집단 지성 API

OpenRouter Fusion API는 여러 모델을 병렬 실행하고 심사 모델이 결과를 종합해 단일 답변으로 제공한다. 단일 모델의 한계를 집단 지성으로 극복하는 새로운 API 패러다임으로 주목받는다.

AI 에이전트 플랫폼에 뭉칫돈

Respond.io가 6250만 달러를 유치하며 북미·유럽 시장 진출과 인수합병을 가속화한다. 비즈니스 메시징을 AI 에이전트로 자동화하는 플랫폼 시장에 투자 열기가 이어지고 있다.
